A local, single-process crypto portfolio dashboard: one Node.js file serves a static page and a
JSON API — no framework, no build step, no runtime dependencies.

- Run: `npm start` (no install step, no build step).
- Test: `npm run e2e`. **No unit tests, ever** — see [agents/testing.md](agents/testing.md).
- Code style: see [agents/code-style.md](agents/code-style.md).
- Architecture constraints: see [agents/architecture.md](agents/architecture.md).
